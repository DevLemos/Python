# Python

## O que é Python?

`Python` é uma linguagem de programação open-source criada pelo programador holandês `Guido Van Rossum`. Uma das principais ideias dele, era fazer com que os programadores que passavam mais tempo lendo códigos do que escrevendo utilizasse uma linguagem fácil de ler, foi ai que ele criou o `python`.

## Instalação do Python

- Baixar o Python 3: `https://www.python.org/downloads/`
- Junto com o Python vem um shell interativo chamado `IDLE (Interactive Development Environment)`. Ele é útil quando queremos fazer testes simples, testar trechos de códigos e escrever programas curtos.
